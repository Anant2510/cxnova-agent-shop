## Kinds of work

| Work | Default tier | Effort | What it covers |
|---|---|---|---|
| extract | fast | low | Pull facts, quotes or notes out of supplied text; little reasoning |
| label | fast | low | Name, tag or expand short items (cluster names, keyword ideas, likely questions) |
| repair | fast | low | Fix listed rule failures in an existing draft (length, banned words, missing parts) |
| copywrite | balanced | medium | Short on-brand copy: emails, InMail, social posts, press releases, tailored sections |
| longform | balanced | medium | Long-form writing: outlines, articles, revisions |
| summarize | balanced | medium | Final summaries in a chosen format from extracted notes |
| translate | balanced | medium | Translation and post-editing with glossary and do-not-translate rules |
| narrate | balanced | medium | Explain results the code already computed (audits, statistics, charts) |
| plan_document | balanced | medium | Structured planning documents: campaign briefs, run plans |
| analyze | pro | high | Reason over evidence to find insights and recommendations |
| review | pro | high | Critique a draft against goals and guardrails |
| query | pro | high | Turn a business question into a governed query or SQL |
| design | pro | high | Design a structure (content models, information architecture) |
| vision | pro | medium | Read images: designs, screenshots, charts |
| experiment | complex | high | Experiment design: hypotheses, metrics, variants and risks |
| code | complex | high | Write executable changes (DOM patches, CSS, scripts) that must run first time |
| synthesis | fast | low | One-paragraph roll-up of a finished run |
